# 프로덕트 관리

#### 1.   프로덕트 기능 개요

프로젝트를 프로덕트 단위로 관리하여, 각 프로덕트 별 프로젝트 대시보드와 통계 정보를 확인할 수 있습니다.&#x20;

※ Product Manager Role이 없다면 메뉴 비 활성화됩니다. ([프로덕트 Role 설정 방법](1q-role.md))



#### 2. 새로운 프로덕트 생성하기

좌측 메뉴 Product Management에서 \[Add New Product] 버튼 클릭해서 프로덕트 생성합니다.

<div align="left"><figure><img src="../.gitbook/assets/image (103).png" alt="" width="563"><figcaption></figcaption></figure></div>



필수 값인 **프로덕트 이름**과 **프로덕트 매니저**를 선택합니다.

<div align="left"><figure><img src="../.gitbook/assets/image (105).png" alt="" width="563"><figcaption></figcaption></figure></div>

* **Product Name:** 신규로 등록할 프로덕트의 이름을 입력합니다.
* **Product Manager:** 해당 프로덕트를 담당하는 관리자를 선택합니다. 선택된 사용자는 프로덕트 관리 권한을 가집니다.
* **Applied Model:** 프로덕트에 적용되는 모델 또는 제품 유형을 입력합니다.(예: 서비스 모델, 배포 모델 등)
* **Usage Scope:** 프로덕트의 사용 범위 또는 활용 목적을 입력합니다. (예: 내부용, 외부 배포용 등)
* **Structure Engineering:** 프로덕트의 구조 또는 엔지니어링 유형을 선택합니다.
* **Inspection Date:** 프로덕트에 대한 점검 예정 날짜를 선택합니다.
* **Release Date:** 프로덕트의 출시 예정 날짜를 선택합니다.
* **Development Department:** 해당 프로덕트를 개발한 부서를 선택합니다.
* **Main Contact:** 프로덕트 주요담당자 연락처 정보를 입력합니다.



#### 3. 프로덕트에 프로젝트 추가하기

\[Assign Project] 버튼 클릭해서 추가할 프로젝트를 선택합니다.

<div align="left"><figure><img src="../.gitbook/assets/image (106).png" alt="" width="563"><figcaption></figcaption></figure></div>



* 프로젝트 목록에서 프로젝트를 선택하면, 해당 프로젝트에서 검증이 완료된 모든 버전(차수) 목록이 표시됩니다.
* 검증이 완료된 Ready 단계의 버전(차수) 목록만 표시됩니다.
* 선택된 프로젝트는 체크박스로 표시됩니다.&#x20;

<div align="left"><figure><img src="../.gitbook/assets/image (107).png" alt="" width="563"><figcaption></figcaption></figure></div>



* 추가한 프로젝트는 기본 그룹(Default Group)에 자동으로 추가됩니다.

<div align="left"><figure><img src="../.gitbook/assets/image (109).png" alt="" width="563"><figcaption></figcaption></figure></div>



#### 4. 프로덕트 그룹 생성하기

\[Add New Group] 클릭해서 새로운 그룹을 추가합니다.

<div align="left"><figure><img src="../.gitbook/assets/image (108).png" alt="" width="563"><figcaption></figcaption></figure></div>



그룹 명과 색상을 지정해서 그룹 추가 완료합니다.

<div align="left"><figure><img src="../.gitbook/assets/image (110).png" alt=""><figcaption></figcaption></figure></div>



기본 그룹(Default Group)에 포함된 프로젝트를 드래그 앤 드롭하여 원하는 그룹에 할당할 수 있습니다.

<div align="left"><figure><img src="../.gitbook/assets/프로덕트.png" alt="" width="563"><figcaption></figcaption></figure></div>



#### 5. 프로덕트 내보내기

**5.1. 그룹별 내보내기**

\[Merged Group Component] 버튼을 클릭하면, 선택한 그룹에 포함된 프로젝트들의 컴포넌트 목록을 통합해서 표시합니다.

<div align="left"><figure><img src="../.gitbook/assets/image (111).png" alt="" width="563"><figcaption></figcaption></figure></div>



이 화면에서는 여러 프로젝트에 포함된 컴포넌트를 통합하여 확인할 수 있으며, 내보낼 SBOM 형식을 선택해서 다운로드할 수 있습니다.

<div align="left"><figure><img src="../.gitbook/assets/image (115).png" alt="" width="563"><figcaption></figcaption></figure></div>



**5.2. 프로덕트 전체 내보내기**

상단의 \[Merged Product Components] 버튼을 클릭하면, 해당 프로덕트에 포함된 프로젝트들의 모든 컴포넌트 목록이 표시되며, 이를 SBOM 형식으로 다운로드할 수 있습니다.

<figure><img src="../.gitbook/assets/image (117).png" alt=""><figcaption></figcaption></figure>



#### 6. 프로덕트 복사하기

상단의 \[Clone Product] 버튼을 클릭해서 프로덕트를 복사할 수 있습니다.

<figure><img src="../.gitbook/assets/image (116).png" alt=""><figcaption></figcaption></figure>

<div align="left"><figure><img src="../.gitbook/assets/image (118).png" alt="" width="224"><figcaption></figcaption></figure></div>



기존 프로덕트의 그룹과 프로젝트 목록 그대로 복사하여 새로운 프로덕트를 생성합니다.

<div align="left"><figure><img src="../.gitbook/assets/image (121).png" alt="" width="563"><figcaption></figcaption></figure></div>
