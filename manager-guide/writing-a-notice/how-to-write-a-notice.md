# How to write a notice

#### 1. Notice Workflow Stage Descriptions

**Step 1 - Write 1/2**

* Click the \[Write Notice Information] button to begin drafting the notice.

<div align="left"><figure><img src="../../.gitbook/assets/image (140).png" alt="" width="563"><figcaption></figcaption></figure></div>



**Step 1.1 - Writing the Notice Header**

First, write the Notice Header. This content appears at the top of the notice. You can configure the default values for this header in the [Preferences](../preferences/notice-header-settings.md) menu.

<div align="left"><figure><img src="../../.gitbook/assets/image (141).png" alt="" width="563"><figcaption></figcaption></figure></div>



**Step 1.2 - Writing Notice Items**

* By clicking a component, you can write the URL, Copyright, and License Text to be included in the notice.
* If existing data is available in the database, those values will be automatically displayed as the default values.
* By selecting the Select option, you can choose from a list of previously written items.
* By clicking Custom, you can write new information from scratch.
* Click Next at the bottom to move to the next component.

<div align="left"><figure><img src="../../.gitbook/assets/image (143).png" alt="" width="563"><figcaption></figcaption></figure></div>



**Step 2 - Review**

* After finishing the writing process for the notice, you must request a review. Click the \[Confirm Notice] button to complete the notice writing phase.

<div align="left"><figure><img src="../../.gitbook/assets/image (108).png" alt="" width="563"><figcaption></figcaption></figure></div>



**Step 3 - Notice(Downloading the Notice)**

* Once the notice writing is finalized, you can click the \[Download] button to download the notice in either Text or HTML format.

<div align="left"><figure><img src="../../.gitbook/assets/image (145).png" alt="" width="563"><figcaption></figcaption></figure></div>
