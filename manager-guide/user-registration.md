# User Registration

#### 1. Registering a User

* Click the \[Add User] button in the System -> User menu.

<div align="left"><figure><img src="../.gitbook/assets/image (43).png" alt="" width="563"><figcaption></figcaption></figure></div>



* Items marked in red are mandatory. Please select the role to be assigned to the account from the Role field. Click the \[Save] button to register the new user.

<div align="left"><figure><img src="../.gitbook/assets/image (44).png" alt="" width="563"><figcaption></figcaption></figure></div>



#### 2. Editing a User

Click on the user you wish to edit from the user list, then click the \[Edit Information] button to modify the user's details.

<div align="left"><figure><img src="../.gitbook/assets/image (73).png" alt="" width="563"><figcaption></figcaption></figure></div>
