# Notification Function

#### 1.  Email Server Configuration (Required Prerequisite)

* To use the email notification function, the [Email Server settings](preferences/server-and-service-integration-settings.md) must first be configured in the Preferences menu.



#### 2. Configuring Email Reception Settings

* Click on your User Information (Profile icon) on the top right, then select \[Profile Settings]. In the&#x20;

<div align="left"><figure><img src="../.gitbook/assets/image (103).png" alt="" width="563"><figcaption></figcaption></figure></div>



* Mail Reception section, you can enable or disable email notifications.

<div align="left"><figure><img src="../.gitbook/assets/image (104).png" alt="" width="533"><figcaption></figcaption></figure></div>

<mark style="background-color:yellow;">※</mark> <mark style="background-color:yellow;">Once both of the above settings are complete, the following email notifications will be sent</mark>



**CVE Notifications**

* If a new CVE is identified in a project, a notification email is sent to the project creator and members.
* These notifications are sent in English.

<div align="left"><figure><img src="../.gitbook/assets/image (102).png" alt="" width="411"><figcaption></figcaption></figure></div>



**Project Verification Workflow Notifications**

* A notification email is sent to the project creator and members each time the verification workflow progresses to a new stage.
* These emails are sent in the language selected by the user.

<div align="left"><figure><img src="../.gitbook/assets/image (101).png" alt="" width="458"><figcaption></figcaption></figure></div>
