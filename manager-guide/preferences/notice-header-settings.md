# NOTICE HEADER Settings

#### 1. Notice Header Configuration

* In **System > Preferences > NOTICE HEADER**, you can configure the default Header values that will appear in the outputted notices.
* This setting allows you to define the default Notice Header that is automatically entered when a new notice is created.
* If an administrator pre-registers fixed phrases (such as standard copyright statements) that appear repeatedly at the top of every notice, those contents will be automatically filled in as the default values during the notice writing process.
