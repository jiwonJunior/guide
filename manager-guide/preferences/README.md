# Preferences

#### Preferences Menu Overview

1. The System > Preferences menu is only visible to the System Administrator (SUPERUSER).
2. The following various items can be configured in this menu:

* [Server and Service Integration Settings](server-and-service-integration-settings.md)
* [Identification Rule Settings](identification-rule-settings.md)
* [Tool, Language, and Other Settings](tool-locale-and-other-settings.md)
* [Nexus Import Settings](nexus-import-settings.md)
* [FossID Import Settings](fossid-import-settings.md)
* [NOTICE HEADER Settings](notice-header-settings.md)
