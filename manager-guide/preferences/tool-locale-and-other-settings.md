# Tool, Locale , and Other Settings

#### Tool, Language, and Other Settings Overview

<div align="left"><figure><img src="../../.gitbook/assets/image (214).png" alt="" width="563"><figcaption></figcaption></figure></div>

#### 1. Scan Tool Settings

* In the Usage Verif. Tools menu, you can enable or disable specific scan tools. Only the selected tools will be displayed in the system. The Clarity tool is enabled by default.

#### 2. HTTP Client Timeout Settings

* In HTTP Client Timeout (seconds), you can set the maximum duration the client waits for a response after a request. If the specified time is exceeded, the connection will automatically terminate.

#### 3. Default Locale Settings

In Default Locale, specify the default language and region to be used throughout the system.

#### 4. CVE Synchronization (Crawling) Settings

* In CVE Crawling Time, you can set the specific time (HH:mm) for the CVE crawling to execute. This process runs once a day at the scheduled time.

#### 5. Project Completion Request Date Settings

* In Default Completion Request Offset, you can set the default value for a project's expected completion date.

#### 6. Verification Timeout Settings

In the Verification Timeout section, you can set the response time limit (Timeout) after an API request is sent when performing file verification through the verification tools.

#### 7. Use Preview Settings

* In Use Preview, you can enable or disable the pre-review function. When enabled, the Previews List menu is added under the Project menu.

#### 8. Synchronizing Component and License Information

Click the \[Sync] button in Genesis Sync to synchronize component and license information. You can verify the synchronized data in the Open Source menu.

* **Sync**: Continues the synchronization from the point it last completed.
* **Full Sync**: Restarts the synchronization from the very beginning to fetch all component licenses again.
