# Nexus Import Settings

#### 1. Nexus Import Settings

In **System > Preferences > NEXUS SETTINGS**, you can enable or disable the feature and configure the necessary URL.

<figure><img src="../../.gitbook/assets/image (158).png" alt=""><figcaption></figcaption></figure>

#### 2. Component Agent URL

* Set the URL that allows the Component Agent to communicate with the system.

#### 3. Using Nexus Import

* In Use NEXUS Import, you can toggle the Nexus Import feature on or off. When activated, the NEXUS Import menu will be added under the Project menu.
