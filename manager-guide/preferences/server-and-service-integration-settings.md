# Server and Service Integration Settings

#### 1. Mail Server Settings

* This section is for configuring the mail server that sends out system notification emails (such as CVE alerts and workflow emails). You can set the SMTP server information to ensure the system performs email transmissions correctly.

<figure><img src="../../.gitbook/assets/image (32).png" alt=""><figcaption></figcaption></figure>



#### 2.  FossID Server Settings

These settings allow ClaritySC to send API requests to the FossID server and retrieve scan results. This includes the necessary connection information for integrating the FossID server.

<figure><img src="../../.gitbook/assets/image (30).png" alt=""><figcaption></figcaption></figure>



#### 3. Clarity Server Settings

* These settings allow ClaritySC to send API requests to the Clarity server and retrieve scan results. This includes the necessary connection information for integrating the Clarity server.
* You can configure the system to bypass certain workflow stages using the **Skip Clarity Workflow** option.

<div align="left"><figure><img src="../../.gitbook/assets/image (107).png" alt=""><figcaption></figcaption></figure></div>



#### 4. ClarityAIR Server Settings

You can configure the connection information required to integrate the ClarityAIR server with ClaritySC. The server configuration must be completed to send API requests to the ClarityAIR server and retrieve verification results.

<figure><img src="../../.gitbook/assets/image (215).png" alt=""><figcaption></figcaption></figure>
