# Identification Rule Settings

#### Identification Rule Configuration

The **System > Preferences > ID Format Settings** menu is used to configure the rules (Prefix + Number of Serial Digits) for generating unique IDs for projects, verification reports, and notice information. These settings determine the formatting style of the IDs automatically generated by the system..
