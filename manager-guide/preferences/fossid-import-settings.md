# FossID Import Settings

#### FossID Import Functionality

In **System > Preferences > FOSSID IMPORT SETTINGS**, you can import previously scanned FossID projects and set the default values for the projects that will be automatically created.

<figure><img src="../../.gitbook/assets/image (131).png" alt=""><figcaption></figcaption></figure>



1. **Asset Classification**

* This sets the default Asset Importance level for projects automatically created during a FossID import.



2.  **License Policy**

    * This sets the default License Policy to be applied to the projects automatically created during a FossID import.


3. **Distribution Scope**

* This sets the default Distribution Scope (Internal / External / SaaS) for projects automatically created during a FossID import.



4. **License**

* This sets the Representative License Type (Commercial / Open Source, etc.) for the projects automatically created during a FossID import.



5. **Import Projects**&#x20;

* Clicking the \[Import] button will display a detailed configuration popup window for importing FossID projects.

<div align="left"><figure><img src="../../.gitbook/assets/image (133).png" alt="" width="437"><figcaption></figcaption></figure></div>

&#x20; **a. Ignore Existing Project**

* Set whether to import duplicate projects. This determines the action if an identical project already exists in the system.&#x20;

&#x20; **b. All FossID Projects**

* Imports every project from the FossID server. (Please note that this process may take a long time.)

&#x20; **c. Date Range**

* Imports all projects from a specific period, such as the last week or a custom-defined date range.

&#x20; **d. FossID Project Code**

* Imports specific projects by entering their FossID Project Codes. You can import multiple projects simultaneously by separating the codes with a comma (,).

***

6. **Import History**

* This section allows you to view the list of imported FossID projects.
