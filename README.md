# What is ClaritySC?

#### What is ClaritySC?

ClaritySC (Clarity Supply Chain) is an open-source management system designed for companies to proactively manage risks that may arise from using open-source software. Through the ClaritySC Management Portal (CSC), companies can perform open-source verification to prevent potential issues before development and deployment. Furthermore, it is an integrated SBOM management platform that supports various SBOM management functions and offers high scalability.

#### Why do we need CSC?

1. In today's software development environment, the use of open source is essential, but it also introduces the following risks:
   1. Potential for license policy violations
   2. Discovery of vulnerabilities (CVE) within open source
2. **The importance of accuracy in detection**: It is crucial how accurately licenses and vulnerabilities (CVE) are detected during verification. CSC provides reliable results by utilizing verification tools such as Clarity and FossID.
3. **Submission of results**: After verification, you can generate verification reports (SBOM) and notices to submit to required parties.
4. **Efficient SBOM management**: CSC provides various SBOM features to help companies manage SBOMs, which are otherwise difficult to maintain.



***

#### 3 Key Strengths of CSC

1. Customizable License Policies: Set license policies according to company standards.
2. Flexible Security Vulnerability Settings: Configure security vulnerability settings based on the importance of the company's assets.
3. Comprehensive SBOM Management: Offers a variety of SBOM management functions, including:
   * SBOM Import
   * SBOM Merge
   * SBOM Comparison
