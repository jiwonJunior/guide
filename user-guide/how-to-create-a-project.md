# How to Create a Project

※ Users without Manager or Product Manager **roles** cannot create a new project. For detailed information on assigning permissions, please refer to the [\[How to Set Roles\]](../manager-guide/user-role-management.md) section.



#### Create a New Project

* There are two methods to create a new project.



#### 1. Creating from the Project Menu

In the Project > Project List menu, click the \[Add new project] button to create a new project.

<figure><img src="../.gitbook/assets/image (46).png" alt=""><figcaption></figcaption></figure>





**1.1. Entering New Project Information**

* In the "Add New Project" window, enter the required values marked in red and assign a Project Manager for this project.
* Select the project's Asset Classification, Distribution, License Policy, and Primary License. If left unselected, default values will be applied.
* Click the \[Save] button to create the new project.

<figure><img src="../.gitbook/assets/image (197).png" alt=""><figcaption></figcaption></figure>

* **Project Name**: Enter the name of the new project to be registered.
* **Project Manager**: Designates the project manager. (Only accounts with Project Manager permissions will be displayed)
* **Product Name**: Selects the product for this project.
* **Product Name**: Select the product that this project will belong to.
* **Completion Request Date**: Enter the expected completion date of the project. ([Default values can be configured in the settings](../manager-guide/preferences/tool-locale-and-other-settings.md#id-8)).
* **Asset Classification**: Set the asset importance level for the project.
* **Distribution**: Specify whether the project will be provided as Internal, External, or SaaS. The default value is SaaS.
* **License Policy**: Select the license policy to be applied to the project.
* **License**: Specify the primary license for the project. The default value is Commercial License; select an open-source license only if the project is being released as open source.
* **Preview List**: Clicking this opens the "Select Preview" popup, where you can select the desired preview items.
* **Remark**: You can add additional notes or comments regarding the project.
* **Document**: You can attach additional documents or files related to the project.

***



**1.2. Project Details**

* In Project Details, you can check project information and the list of pre-reviewed components, and proceed with verification using the selected scanning tool.

<figure><img src="../.gitbook/assets/image (49).png" alt=""><figcaption></figcaption></figure>





**1.3. PREVIEW COMPNENT LIST**

By clicking \[Select Preview] and choosing pre-review items, the list of pre-reviewed components will be displayed.

<figure><img src="../.gitbook/assets/image (50).png" alt=""><figcaption></figcaption></figure>





**1.4. Start verification**

* Clicking the \[Add Verification Request] button starts the file analysis through the selected scanning tool, followed by an automated verification process.

<figure><img src="../.gitbook/assets/image (27).png" alt=""><figcaption></figcaption></figure>



***

* This is the second method for creating a new project, where you can add a project directly within the Product Management menu. For detailed registration steps, please refer to the [\[Creating a Project from a Product\]](../manager-guide/product-management.md#id-3.-product-manager-permissions) section.
