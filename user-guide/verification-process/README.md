# Verification Process

#### 1. Verification Feature Overview

* ClaritySC supports Clarity, FossID,ClarityAIR verification tools, and SBOM Import functions.
* In the project, you can request file analysis by selecting verification tools such as Clarity, FossID, and ClarityAIR, as well as SBOM Import, and manage the results through the verification workflow. Additionally, you can generate an SBOM based on the verification results.

#### 2. Verification Workflow Description

* Clarity, FossID, ClairtyAIR and SBOM each have their own unique verification workflow stages.
* In the case of Clarity, you can complete the verification by moving the workflow directly to the Ready stage without intermediate steps.
  * This feature can be configured by checking the Skip Clarity Workflow option in the settings menu (System > Preferences > Server Settings > Clarity Server). ([How to configure the Clarity workflow](../../manager-guide/preferences/server-and-service-integration-settings.md))
